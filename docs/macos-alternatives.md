# Аналоги OmaQuote для macOS

Дата исследования: 26 сентября 2026 года.

Это исследование вариантов, не спецификация новой реализации. Проверены документация, страницы разработчиков, лицензии и отдельные исходники. Приложения не устанавливались и не запускались; совместимость с конкретной конфигурацией Mac экспериментально не подтверждена.

## Вывод

Готовые решения существуют. Ближайшее специализированное приложение — Desktop Quote. Среди открытых платформ функционально подходит Übersicht, но из-за длительного отсутствия коммитов его стоит рассматривать как экспериментальный вариант, а не основной фундамент нового приложения. Полного подтверждённого open-source аналога всех функций OmaQuote среди проверенных проектов не найдено. Самостоятельное нативное приложение технически реалистично; основной риск — интеграция с поведением рабочего стола и сменой системных обоев, а не отображение текста.

## Что сопоставлялось

По [README](https://github.com/snikulin/omaquote/blob/main/README.md), [доменному описанию](https://github.com/snikulin/omaquote/blob/main/CONTEXT.md), [QuoteSurface.qml](https://github.com/snikulin/omaquote/blob/main/QuoteSurface.qml) и [QuoteEngine.js](https://github.com/snikulin/omaquote/blob/main/lib/QuoteEngine.js):

- Quote Surface над обоями и под приложениями, пропускающая клики.
- Одна активная Quote на всех дисплеях без изменения обоев.
- Локальная JSON Quote Collection; перезагрузка с сохранением последней корректной версии.
- Shuffle/Random, Interval, Wallpaper Change, Presentation History, Automatic Advance Pause.
- Quote Controls в системной панели и команды для автоматизации.
- Позиционирование, Text Fit, настраиваемые цвета и оформление.

## Готовые варианты

### Desktop Quote — ближайший по назначению

[Страница разработчика в App Store](https://apps.apple.com/ca/app/desktop-quote/id1324292348?mt=12) заявляет текст поверх существующих обоев, собственные текстовые коллекции, настройку положения/шрифта/цвета, произвольное расписание, случайный и последовательный порядок, сохранение позиции. История версий подтверждает Apple Silicon и несколько мониторов. Последняя указанная версия — 2.06 от 19.09.2022; приложение платное, цена зависит от магазина.

Открытый исходный код не найден. Не подтверждены точная семантика истории и паузы, JSON-совместимость, команды, реакция на Wallpaper Change и актуальная совместимость со всеми режимами macOS. Первый кандидат для проверки без разработки, если открытость не обязательна.

### Übersicht — открытая платформа с риском сопровождения

Уточнение после проверки истории default branch: последний коммит — [859a7d7 от 04.12.2023](https://github.com/felixhageloh/uebersicht/commit/859a7d70). Более позднее поле GitHub `pushed_at` не означает более свежего коммита в основной ветке. Первоначальная рекомендация платформы была слишком сильной без этой оговорки.

[Официальный сайт](https://tracesof.net/uebersicht/) предлагает приложение для macOS 12+, JavaScript/React JSX-виджеты, системные команды, CSS и периодическое обновление. Лицензия самой платформы — GPL-3.0-or-later. [Документация](https://github.com/felixhageloh/uebersicht) описывает обновление при редактировании файлов, управление состоянием и AppleScript.

В [UBWindow.m](https://github.com/felixhageloh/uebersicht/blob/master/Uebersicht/UBWindow.m) действительно реализованы прозрачные окна desktop-уровня, пропуск мыши и участие во всех Spaces. Это не генератор новых картинок обоев.

Есть готовые примеры:

- [tetutaro/uebersicht_widgets](https://github.com/tetutaro/uebersicht_widgets) — MIT; [quote.jsx](https://github.com/tetutaro/uebersicht_widgets/blob/master/quote.jsx) получает цитату дня от ZenQuotes раз в сутки. Готовый простой виджет, но без своей локальной коллекции и контролов OmaQuote. Работа внешнего API не проверялась.
- [FeringaMind/Ubersicht-Widgets](https://github.com/FeringaMind/Ubersicht-Widgets) — случайная цитата из локального `quotes.txt` по интервалу, формат `QUOTE : AUTHOR`. [Код](https://github.com/FeringaMind/Ubersicht-Widgets/blob/main/Quotes/index.jsx) прочитан: это небольшой пример без полноценной валидации, истории и общего движка состояния. Файл лицензии в проверенном дереве отсутствует; не считаю его подтверждённым свободно лицензированным компонентом для копирования.

Практический вариант: написать собственный небольшой виджет, который читает существующий формат OmaQuote. Для одинаковой цитаты на разных дисплеях выбор должен происходить в общем состоянии, а не независимо в каждом экземпляре виджета. Это проектное предложение, не готовая функция найденных примеров.

Совместимость требует проверки: есть [сообщение о потере выбора экранов после сна](https://github.com/felixhageloh/uebersicht/issues/522). При этом [обращение о запуске на Tahoe 26.4](https://github.com/felixhageloh/uebersicht/issues/549) закрыто самим автором как проблема его системных настроек; оно не доказывает общую несовместимость. В нём отображение виджетов продолжало работать.

### WallVerse — открытый, но меняет обои

[Репозиторий](https://github.com/aref-dev/WallVerse), MIT. [Пакет PyPI](https://pypi.org/project/wallverse/) заявляет macOS, свои цитаты, оформление, таймер, системный трей и Python 3.10+. Опубликованная версия — 0.1.0 от 16.12.2023, статус Alpha.

[Исходник wallpaper.py](https://github.com/aref-dev/WallVerse/blob/master/wallverse/wallpaper.py) рисует цитату в PNG через Pillow и на macOS назначает его обоями через AppleScript/Finder. Это прямое отличие от Quote Surface OmaQuote: приложение управляет картинкой рабочего стола. Подходит, если допустима замена обоев; для сохранения независимой системной ротации я бы его не выбирал.

### Plash — удобный вариант с HTML, уже не open source

[Документация автора](https://sindresorhus.com/plash) подтверждает локальные HTML-страницы, прозрачный фон, пользовательский JavaScript/CSS и слой над настоящими обоями. Можно сделать страницу с локальными цитатами. Ограничение: штатно выбирается один дисплей; полноценная работа с несколькими дисплеями не реализована. Команды next/previous переключают страницы, а не историю цитат внутри страницы.

[Текущий README](https://github.com/sindresorhus/Plash#where-is-the-source-code) прямо сообщает, что приложение больше не open source. Старые подборки, называющие его открытым, не описывают текущую версию.

### Другие найденные приложения

[Hologram](https://gethologram.com/) предлагает виджеты цитат и создание собственных HTML/CSS/JS-виджетов, но это более широкая система обоев и виджетов; открытость и совместимость с коллекцией OmaQuote не подтверждены. [Orbl](https://www.orbl.app/) предлагает цитату дня и прозрачное отображение поверх своих обоев пользователя; собственная коллекция, аналог истории OmaQuote и публичный исходный код не подтверждены. Оба менее точно соответствуют запросу, чем Desktop Quote или собственный виджет Übersicht.

## Собственная реализация

Рекомендация: Swift + AppKit для управления окнами, SwiftUI для Quote Controls и настроек. QML-поверхность использует Quickshell/Wayland и напрямую не переносится. При этом чистая логика уже отделена в JavaScript: `lib/QuoteEngine.js` и `lib/JsonDocuments.js` не обращаются к Qt API, кроме директивы `.pragma library` в начале. Для MVP их можно адаптировать к встроенному [JavaScriptCore](https://developer.apple.com/documentation/javascriptcore), удалив эту директиву при упаковке и добавив мост Swift ↔ JS. Это не требует Qt, Node или WebView. Совместимость таким запуском ещё не проверена. Перенос логики на Swift — альтернативный выбор ради одного языка, а не техническая необходимость.

### Quote Surface

Apple документирует [SwiftUI WindowLevel.desktop](https://developer.apple.com/documentation/swiftui/windowlevel/desktop): окно располагается над обоями и за остальным содержимым. API доступен с macOS 15, что проверено в [машиночитаемой документации Apple](https://developer.apple.com/tutorials/data/documentation/swiftui/windowlevel/desktop.json).

Для управляемых поверхностей на нескольких экранах целесообразны отдельные прозрачные AppKit NSWindow и общая модель активной Quote. [ignoresMouseEvents](https://developer.apple.com/documentation/appkit/nswindow/ignoresmouseevents) пропускает мышь; [canJoinAllSpaces](https://developer.apple.com/documentation/appkit/nswindow/collectionbehavior-swift.struct/canjoinallspaces) отвечает за видимость в Spaces. Точное размещение относительно wallpaper и Finder icons надо подтвердить прототипом на выбранной версии macOS. Пример AppKit-паттерна существует в исходниках Übersicht, приведённых выше.

Таймер, JSON, история, пауза, Text Fit, сохранение состояния и меню не представляют особого платформенного препятствия. Аналог цветов Omarchy следует определить отдельно: системные светлая/тёмная темы и собственная палитра не равны общей палитре Linux-shell.

Для меню доступен [MenuBarExtra](https://developer.apple.com/documentation/swiftui/menubarextra), для автозапуска — [SMAppService](https://developer.apple.com/documentation/servicemanagement/smappservice). Изменения экранов отслеживаются через [didChangeScreenParametersNotification](https://developer.apple.com/documentation/appkit/nsapplication/didchangescreenparametersnotification), выход из сна — через [didWakeNotification](https://developer.apple.com/documentation/appkit/nsworkspace/didwakenotification). Инженерный вывод: для базового отображения собственных окон не нужны Accessibility, Screen Recording, административные права или отключение SIP. Это не утверждение о разрешениях сторонних приложений. Подпись и notarization для распространения — отдельная часть упаковки.

### Где остаётся неопределённость

1. **Spaces, Show Desktop, Mission Control, Stage Manager.** Наличие API не заменяет проверку их сочетаний. Нужно проверить отсутствие фокуса/кражи кликов, положение за обычными и полноэкранными приложениями, возврат после Show Desktop.
2. **Несколько дисплеев и сон.** Проверить подключение и отключение, разные масштабы Retina, изменение разрешения, выход из сна. Все поверхности должны отображать одну Quote, а переподключение не должно вызывать Advance.
3. **Wallpaper Change.** [NSWorkspace.desktopImageURL(for:)](https://developer.apple.com/documentation/appkit/nsworkspace/desktopimageurl(for:)) позволяет читать URL, но универсальный документированный сигнал изменения всех типов обоев не найден. Сравнение URL с интервалом — возможная ограниченная реализация для файловых обоев. Изменение кадра Dynamic/Aerial при прежнем URL не обнаруживается этим методом; разные обои в Spaces требуют отдельной семантики. Надёжная альтернатива — явная команда от используемого переключателя обоев. Основные Interval и ручная навигация могут работать независимо.
4. **Генерация новой картинки вместо Quote Surface.** Технически возможна через [setDesktopImageURL](https://developer.apple.com/documentation/appkit/nsworkspace/setdesktopimageurl(_:for:options:)), но меняет системные обои. [Apple Frameworks Engineer](https://developer.apple.com/forums/thread/834630) подтверждает отсутствие API для назначения изображения сразу всем Spaces одного экрана. Поэтому этот вариант не выбран как основной.

### Объём работ

Ориентировочная инженерная оценка для одного разработчика, знакомого со стеком, а не обещание сроков:

| Результат | Оценка |
| --- | --- |
| Простой виджет Übersicht: локальная коллекция, оформление, таймер | 0,5–2 рабочих дня |
| Нативный прототип Quote Surface с проверкой окон и экранов | 1–2 дня |
| Нативный MVP: коллекция, таймер, история, пауза, меню, сохранение | 3–7 дней суммарно |
| Версия для повседневного использования и распространения, проверенная на выбранной матрице macOS | 2–4 недели суммарно |

Оценки не включают обещание универсальной реакции на любые системные обои. Совместимость со старыми macOS, широкая матрица оборудования и дополнительные способы автоматизации могут увеличить объём.

## Предлагаемый выбор

- Если нужен результат без разработки и допустимо закрытое приложение — первым проверить Desktop Quote.
- Если open source обязателен и допустим отдельный движок виджетов — Übersicht можно попробовать с небольшим виджетом под JSON OmaQuote, учитывая длительное отсутствие коммитов.
- Если нужна самостоятельная компактная утилита с точным поведением OmaQuote — Swift/AppKit. Начать с прототипа окон на реальных Spaces/дисплеях, затем переносить поведение движка. Wallpaper Change оставить явно ограниченной интеграцией до её проверки.
